# Revisión UI/UX — ARTI

Revisión aplicada con UI/UX Pro Max y Web Interface Guidelines, sobre la landing y el recorrido principal de la demo estática.

- Identidad: variantes originales del kit sobre superficies clara y oscura; símbolo y logos con dimensiones y proporciones conservadas.
- Temas: control accesible, preferencia inicial del sistema y selección persistida; fondos, texto y controles nativos ajustados a cada tema.
- Contraste medido de combinaciones principales: tinta/crema 17.8:1, blanco/violeta 6.83:1, violeta/crema 6.49:1, violeta claro/tinta 7.22:1; el contraste de cada fotografía o componente de terceros no se certifica por esta medición.
- Navegación: elementos semánticos, foco visible, enlace para saltar contenido, menú móvil con cierre mediante Escape; opciones de contacto y estado de carga de demo etiquetados.
- Movimiento: entradas y apariciones con opacidad/transformación; la preferencia de movimiento reducido desactiva las transiciones y animaciones.
- Pruebas observadas: página corporativa en anchos de 375, 768 y 1440 CSS px y demo en 375 y escritorio; tema, idioma y menú probados; demo embebida y vistas Cliente y Artista abiertas; búsqueda por nombre verificada. Se corrigieron desbordamientos móviles y el formato de puntuación de la demo.
- Límites: revisión visual y funcional de recorridos representativos, no auditoría formal WCAG ni prueba de todos los flujos, navegadores, lectores de pantalla o dispositivos físicos. La demo heredada es extensa y está en español. El contacto general de ARTI aún no está verificado y el dominio depende de acceso DNS.
